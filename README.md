# Сильные стопы

Приложение для ежедневной лечебной гимнастики (ЛФК) для стоп: подросток занимается дома с телефоном, приложение показывает упражнение, ведёт таймер, считает подходы и подсказывает голосом.

**Открыть:** https://kaknetuz.github.io/silnye-stopy/

Комплекс составлен для плосковальгусной деформации стоп: упражнения укрепляют мышцы, которые поднимают свод и удерживают пятку ровно. Это дополнение к лечению, назначенному ортопедом, а не замена ему. При боли занятие нужно прекратить и обратиться к врачу.

## Что умеет

- **Два варианта занятия на вкладках:** «30 минут» (17 ключевых упражнений) и «Полный» (27 упражнений, около часа). Выбор запоминается.
- **4 блока:** разминка, основной комплекс (лёжа, сидя, стоя), упражнения у стены для осанки, заминка.
- **Схема к каждому упражнению** в стиле «оживший набросок»: карандашный рисунок, линии которого слегка «дышат», ракурс подписан, работающая мышца заштрихована оранжевым, стопы крупным планом детализированы.
- **Таймер:** отсчёт перед стартом, подходы с отдыхом между ними, смена ног, автоматический счёт задержек («держи — расслабь»), счётчик повторений для упражнений без таймера.
- **Сигналы как в табата-таймерах:** длинный сигнал на старт, двойной гонг в конце упражнения, вибрация.
- **Голосовые подсказки** на русском: номер повтора, «смени ногу», «отдых».
- **Музыка во время упражнений:** спокойная мелодия хэндпана в ре мажоре, собственная, генерируется прямо в приложении. Играет только пока идёт упражнение, затихает на отдыхе и под голосовые подсказки.
- **Мотивация:** серия дней подряд и медаль за каждые 7 дней без пропусков; заставка со случайной мотивирующей цитатой при открытии.
- **Перед стартом** — список того, что подготовить (коврик, стул, полотенце, мячи и т. д.) для выбранного варианта.
- **Предупреждение при первом запуске:** комплекс — дополнение к лечению, при боли занятие прекращают.
- **Настройки** (значок шестерёнки): звук, голос, музыка, тема «Авто / Светлая / Тёмная», ежедневное напоминание через Google Календарь или файл календаря, резервная копия прогресса кодом.
- **Работает без интернета** после первого запуска, экран не гаснет во время тренировки.

## Установка на Android

1. Откройте https://kaknetuz.github.io/silnye-stopy/ в Chrome.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран» → «Установить»).
3. Один раз запустите с интернетом — дальше приложение работает офлайн.

Для голосовых подсказок на телефоне должен быть установлен русский голос синтеза речи (Настройки → Система → Язык и ввод → Синтез речи; название пункта зависит от модели).

## Обновления

Приложение открывается сразу из памяти телефона, а свежую версию скачивает в фоне. Новая версия появляется со следующего запуска с интернетом. Номер версии виден внизу главного экрана и в настройках.

## Данные

Приложение ничего никуда не отправляет и не обращается к сторонним серверам — даже шрифты лежат в репозитории. Отметки о занятиях и настройки хранятся только в браузере на телефоне; удаление приложения или очистка данных Chrome их стирает, поэтому в настройках есть резервная копия кодом. Регистрация не нужна.

## Устройство

Без сборки и зависимостей — статические файлы для GitHub Pages:

| Файл | Назначение |
|---|---|
| `index.html` | разметка экранов и подключение файлов |
| `styles.css` | стили, светлая и тёмная темы, шрифты |
| `js/core.js` | общие помощники: работа со страницей, хранилище, даты |
| `js/exercises.js` | упражнения, дозировки, варианты «30 минут» и «Полный», инвентарь |
| `js/anim.js` | анимированные схемы упражнений в стиле «оживший набросок» |
| `js/audio.js` | сигналы, голосовые подсказки, удержание экрана, музыка |
| `js/app.js` | движок тренировки, экраны, настройки, медали, запуск |
| `manifest.webmanifest` | описание приложения для установки на телефон |
| `sw.js` | сервис-воркер: офлайн-режим и быстрый запуск; версию в нём менять не нужно |
| `icon-*.png` | иконки |
| `fonts/` | шрифты Golos Text, Unbounded и Martian Mono (лицензия SIL OFL, файлы лицензий рядом) |
| `tools/build_single.py` | собирает всё в один HTML-файл — для версии, опубликованной в Claude |
| `tests/smoke.test.js` | автотесты на Playwright |
| `.github/workflows/tests.yml` | запуск автотестов на GitHub при каждом изменении |

Технологии: HTML, CSS и JavaScript без фреймворков; схемы — SVG; звук и музыка — Web Audio API; голос — Web Speech API; удержание экрана — Screen Wake Lock API.

Чтобы поправить дозировку или текст упражнения, достаточно изменить `js/exercises.js`. Новый файл скрипта нужно добавить и в `index.html`, и в список `SHELL` в `sw.js` — автотест это проверяет.

## Автотесты

Смоук-тесты на Playwright проверяют, что файлы на месте и не пустые, первый запуск (заставка и предупреждение), вкладки, запуск тренировки с таймером, резервную копию и работу без интернета. На GitHub они запускаются автоматически при каждом изменении (вкладка Actions). Локально:

```
npm install
npx playwright install chromium
npm test
```
